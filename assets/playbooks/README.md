# Playbooks

Domain knowledge as data, not pipeline (CONCEPT.md §10). Each playbook is a YAML-frontmatter markdown file the superagent consumes as prior knowledge — never as a rigid template. An unknown project type does not stop the system; it reasons from scratch and drafts a new playbook in RETRO.

Start from `_template.md`; `web-saas.md` is the first builtin playbook.
