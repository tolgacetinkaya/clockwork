# Mission Arcade artwork

Original AI-generated raster artwork created for Clockwork from the selected Mission Arcade design direction (2026-10-29). No third-party character packs or remote asset dependencies are used.

- `fox.png`: Nova, lilac origami fox.
- `owl.png`: Kara, cream origami owl.
- `turtle.png`: Moss, lime/olive origami turtle.
- `rabbit.png`: cyan origami rabbit with long ears and a round cream tail.
- `red-panda.png`: coral origami red panda with round ears and a cream-ringed tail.
- `puffin.png`: Piko, graphite puffin with orange beak and wind-up crest.
- `platform.png`: neutral task platform; CSS tint reflects recorded task state.
- `quest-terrain.png`: decorative rocky landscape.

Characters are transparent PNGs. React chooses the character and recorded state; CSS supplies restrained state animations and respects reduced motion. These are not rigged 3D models or desktop overlay processes. Portrait species are decorative and never replace real agent role labels.

Project artwork is distributed with the repository under its MIT license. Runtime UI icons remain Lucide icons under their own license.

- `piko-front-sheet.png`: original front-view Piko animation atlas, 4 columns by 5 rows (1122 by 1402 pixels). Rows: idle, walk, work, attention, success. See PIKO_FRONT_SHEET.md for provenance and inspection limits.
